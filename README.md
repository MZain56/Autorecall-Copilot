# Autorecall-Copilot
AutoRecall Copilot: an evaluated agentic RAG system for early detection of car and motorcycle defects.
MSc Data Science capstone, University of Europe for Applied Sciences.

## Data
Official NHTSA complaints and recalls files, downloaded directly from NHTSA (not Kaggle).
The data files are not stored in this repository.
